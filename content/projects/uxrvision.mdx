## What it is

UXRVision runs user research sessions end to end: participants join a test session, session state and metrics persist in real time, and an AI analysis loop on Vercel Edge Functions turns raw sessions into findings quickly.

## How it's built

Supabase handles user authentication, test session state, and relational tables for user test metrics. Vercel Edge Functions keep the AI analysis loop close to the user for fast feedback.

The repository is private, but the product and its URL are public. The journal entries linked below cover the architecture decisions and trade-offs in detail.
