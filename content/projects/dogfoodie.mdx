## What it is

DogFoodie is the open-source core: a public codebase with structured documentation, local-first database syncs, and a place for community-contributed datasets.

## How it's built

Supabase manages dataset storage and schema migrations. Vercel hosts the documentation and open-source previews, so every change to the docs or the code gets a live preview URL.
